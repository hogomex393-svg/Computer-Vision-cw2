# 现场与录制脚本

建议总长 3～4 分钟，不是老师明确规定的硬性时长。录制前必须确认运行的是正式模型，画面不能出现 SYNTHETIC SMOKE。模型未训练或 Nano 未验证时，不拍成“已完成部署”。

## 准备

准备玻璃杯、透明塑料瓶、一个平整透明板；背景选纯色、文字图案和杂乱桌面。保持个人隐私、其他同学面孔与账号信息不入镜。固定一段无隐私的本地视频作为可重复回放，现场摄像头故障时仍能展示。

把 Nano、电源、摄像头、显示器和散热装置连接好，先执行 docs/JETSON.md 的环境检查、引擎一致性和短视频测试。保留 nvpmodel、温度和实测延迟，不临时改变功耗模式后沿用旧数字。

## 镜头顺序

1. 约 30 秒：展示目标与三类标注。说明输出是像素类别，前景叠加可合并显示，不能说成“数出了几个物体”。
2. 约 45 秒：同一回放先运行 S0，再运行验证集选出的模型。画面明确标注 Replay、模型名、输入尺寸和实测时间。解释边界辅助头与教师蒸馏分别在哪个训练阶段发挥作用。
3. 约 60 秒：镜头同时拍到真实 Nano 和实时摄像头结果。移动透明物体，更换背景，展示边缘变化；不要只选一种容易的背景。
4. 约 30～45 秒：展示固定失败案例，如强反光、薄边或纹理混淆。说明改进是否真实有效，不能遮掉退步实验。
5. 约 30 秒：展示从真实 JSON 生成的精度/速度结果，以及 FP32/FP16、256/384/512 和持续运行记录。结束时说明已验证范围和限制。

## 录制证据

保留原始录像到组内存储，不放普通 Git。交付成片、运行命令、模型 SHA256、Nano 环境 JSON、benchmark.json 与 tegrastats.log。摄像头帧率与实际处理 FPS 分开表述。回放不能冒充现场实时摄像头。
