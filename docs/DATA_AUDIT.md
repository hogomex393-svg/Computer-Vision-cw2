# 数据审计与坐标修正

数据来源是作者提供的 Trans10K v1 三个压缩包，下载记录保存文件大小、SHA256 和 ZIP CRC 校验。所有原始图像与掩膜保持原样；训练/评价通过审计清单读取。

## 已核实的训练集方向问题

完整尺寸盘点发现 18 个训练图像/掩膜宽高反置的样本。它们没有可用的 EXIF 方向标记。逐张对照原图、顺时针和逆时针掩膜叠加后，确认如下修正：

- 顺时针 90°：150、1519、1544、1557、2511、2538、2545、2642、2672、2706、2707、3703、3808、467、964、981。
- 逆时针 90°：3751、3788。

这些编号均位于 train/images，后缀为 .jpg。对应掩膜在 train/masks，后缀为 _mask.png。实际配方位于 configs/trans10k_v1_geometry.json，每一项绑定原始图像与掩膜 SHA256，并附检查图位置。修正只旋转整数标签，不插值、不改变类别像素数量、不删掉样本。验证集与测试集未做这类方向修正。

检查图：results/geometry_review_01.jpg、geometry_review_02.jpg、geometry_review_03.jpg。它们展示的是原始人工标签的坐标核对，不是模型预测或性能结果。

作者的旧 [加载器](https://github.com/xieenze/Segment_Transparent_Objects/blob/master/segmentron/data/dataloader/seg_data_base.py) 将图像和掩膜分别缩放到正方形，未检查这种方向问题。直接拉伸不能修复本次发现的错位。这里显式记录训练几何修正；所有学生消融使用同一份清单，不直接拿本项目协议宣称超过原论文分数。

## 执行

```bash
python project.py audit --root DATA --out data/manifests --encoding trans10k_v1 --geometry-overrides configs/trans10k_v1_geometry.json --workers 4
```

未提供修正配方时仍会严格拒绝尺寸不匹配；未审核配方、SHA256 不匹配或未知像素值同样失败。来源索引保留 5000/1000/4428 的官方拆分和全部样本，实际实验使用下述派生清单。

逐样本恢复日志为 audit_rows.jsonl。复查首先核对文件大小、mtime、编码、具体几何配方和审计实现摘要；相同的已验证记录可以复用，改变的样本重新解码。末尾因中断留下的半行会被丢弃并重做，日志中段损坏会明确失败。一个输出目录只允许一个审计写入者。

## 缓存和原图评价

缓存保存模型输入网格上的 RGB 和整数标签。验证与鲁棒性输入也可以预先生成，但评价仍读取原尺寸真值，并在原图网格上计算指标。缓存包含清单 SHA256、预处理实现摘要、尺寸、外观条件和 seed；身份不匹配会拒绝使用。清洁、亮度、模糊和 JPEG 缓存均通过与不使用缓存的路径逐像素相等测试。

原图损坏、未知标签、未解决尺寸问题和跨拆分重复都会使整体验收失败。最终统计与完整异常清单以 data/manifests/audit.json 为准，不能仅凭下载完成或文件数量宣布通过。

## 跨集合重复与实际实验协议

完整审计发现 11 组跨集合的逐像素完全相同图像。原始审计仍保留这些失败记录，没有取消重复检查。为阻止这些样本进入互相污染的训练/选模/测试过程，新增独立的 leak-free-v1 派生清单：

1. 完整保留原测试集 4428 张。
2. 从验证清单排除与测试重复的 validation/hard/images/10223.jpg，剩余 999 张。
3. 从训练清单排除与任一保留验证或测试图相同的 10 张，剩余 4990 张。具体文件在派生 audit.json 的 excluded 中逐项列明。

```bash
python project.py prepare-splits --audit data/manifests --out data/clean_manifests
```

该命令只在原始审计的全部错误恰好是可由记录重建的跨集合重复时工作。未知标签、尺寸错误、缺失/损坏文件等不能通过它绕过。派生完成后再次检查三个集合的 decoded SHA256 交集为空。原始文件与原始清单不删除、不移动，所有正式模型使用同一派生清单。

因此，本项目正式结果明确标为 Trans10K v1 leak-free-v1：4990/999/4428，不冒称使用了未经清洗的 5000/1000/4428 训练/验证协议。组内重复仍按官方测试样本保留，并在审计报告中披露；这里的“无泄漏”专指已经检查的跨集合完全重复，不声称排除了所有近似重复或场景关联。
