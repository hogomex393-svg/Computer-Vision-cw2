## 一 课程要求与项目范围

老师要求：使用视觉模型并解释原理；做有意义的模型改进；至少两种优化；核心推理在 Jetson Nano 运行；评价准确率、速度、延迟、资源与鲁棒性；交付源代码、模型、部署说明、报告、现场演示和演示视频。自建数据集可选。

我们做的是 RGB 图像的透明物体语义分割。输出每个像素的三类标签：背景、透明物件、透明设施。现场展示可合并前景。不是实例分割、物体计数、图像增强，也不要求深度估计、机械臂控制或自主导航。

主线固定为：SegFormer 教师、MobileNetV3 学生、边界辅助监督、输出概率蒸馏、ONNX 导出、Nano TensorRT 推理。优先完成这个闭环，不增加 GAN、多个大模型、复杂反射分离或其他难维护模块。

论文参考：

- TransLAB 代码：https://github.com/xieenze/Segment_Transparent_Objects

| 等级 | 可验证内容 | 交接边界 |
|---|---|---|
| L1 只有 CPU 或缺真实数据 | 完整工程、关键逻辑验证、合成样本训练链路、导出与 ONNX 对齐（依赖允许时） | 不能称为已有有效透明物体模型 |

## 三 数据加载与审计

主数据用 Trans10K v1，官方 5000/1000/4428 train/val/test 划分，前景两类加背景共三类。v2 十一类仅作可选扩展。两版本共享图像，不当独立数据集交叉测试。

优先从官方网盘入口获取数据。下载需要登录、权限或验证码时，不绕过；给我精确的官方下载入口、缺少文件和目标目录。下载器须检查返回的是否真的是压缩包，防止把网页当数据。缺真实数据时可以用明确标注的合成样例验证代码，但不得计算伪装成公开基准的成绩。

实现数据审计：统计文件配对、尺寸、掩膜原始像素值、类别数量、忽略值、分割数量、损坏文件和重复图像。按照实际文件或官方加载器确认类别映射，保留映射说明和可视化。未确认时显式失败，不静默把未知值变成背景。

项目内部统一 background=0、transparent_thing=1、transparent_stuff=2、ignore_index=255；原始编码通过配置显式映射。图像 RGB，掩膜保留整型类别，几何增强同步，掩膜最近邻插值。忽略区不进入损失和指标，填充用 ignore_index。

保存 train/val/test 清单和来源，不将测试集用于选择模型、超参数或现场微调。自采数据按物体或拍摄场次分组，避免相邻视频帧泄漏。公开与自采结果分开。

## 四 需要完整实现的模型与损失

### 教师 T

使用 SegFormer-B2；显存或资源不足时使用 B0，记录原因和实际配置。可采用维护良好的 SegFormer 实现避免旧版依赖，确认与原论文架构一致并注明库。更换为三类输出头，使用可获取的官方或可信预训练权重，在 Trans10K 上微调。教师训练不得被“加载通用预训练权重”替代。

教师冻结、eval、无梯度；只有验证表现合适时才用于正式蒸馏。若不优于学生，先检查数据、训练与容量，不盲目增加模型。

### 学生 S0

ImageNet 预训练 MobileNetV3-Large 编码器，提取约 1/4、1/8、1/16、1/32 尺度特征。使用 1×1 投影、逐级上采样融合、轻量卷积和三类输出头。初始解码通道 64，正式消融前锁定。避免依赖私有脆弱层序号，获取特征后验证尺度和通道。

基础分割损失固定为多类交叉熵＋前景 Dice，忽略背景占比对主结论的干扰。明确缺失类别与全忽略样本的处理，不能产生 NaN。

### 改进 A 边界辅助监督

从真实训练掩膜提取类间边界，边界带宽度配置化并固定。忽略区域及附近无效像素不能被误当边界。浅层或解码特征接轻量辅助头，用平衡 BCE 或固定的 BCE/Dice 组合监督。

边界头仅训练使用，其预测不能成为主分割必需输入。导出时移除后，主 logits 应与训练模型 eval 模式一致。

### 改进 B 蒸馏

输出概率逐像素 KL 蒸馏，支持温度和 T² 缩放，教师 logits 对齐学生网格。先实现均匀有效像素蒸馏，不默认做多层特征蒸馏。

教师和学生看到同一几何增强后的图像；不同归一化分开处理。mask ignore 区不进入损失。辅助与蒸馏开关真正独立关闭，对应分支不产生损失或加载不需要的模型。

总损失：Lseg + λb·Lboundary + λkd·Ldistill。温度与权重只用验证集小范围选择，记录搜索过程。教师与学生需解释网络原理、预训练来源与限制。

边界加权蒸馏作为可选扩展，只有主线完整并且有时间才实现，同时增加均匀蒸馏对照。

## 五 训练与实验自动化

必须交付 T、S0、S1、S2、S3 五个独立配置：

| 配置 | 边界辅助 | 蒸馏 |
|---|---|---|
| T | 教师原设置 | 无 |
| S0 | 无 | 无 |
| S1 | 有 | 无 |
| S2 | 无 | 有 |
| S3 | 有 | 有 |

输入先用 384×384，部署 batch=1；训练 batch 自适应硬件。正式学生实验保持相同主干初始化、数据、输入、增强、优化器、训练预算与选模规则。CPU 短跑只验证链路；GPU 上先短跑估计单轮时间和显存，再明确正式训练预算并执行。不能静默把全部正式实验缩成几个 step。

实现单卡训练、AMP（硬件允许时）、断点恢复、best/last checkpoint、日志及每轮验证。checkpoint 保存模型、优化器、调度器、AMP scaler、epoch/global step、随机状态和配置；说明恢复的可复现边界，不夸大跨平台完全一致性。

提供一个入口顺序运行训练、评价和汇总。支持选择实验、跳过已成功且配置匹配的实验、失败时非零退出和定位日志；不得把旧配置结果混入新表。四个学生实验依次执行，不默认并行争抢同一 GPU。

真实数据与 GPU 可用时执行正式实验，先一个固定 seed；资源充裕时重复 S0 和最终模型三个 seeds。额外训练预算基于环境和课程时间说明，不追求无止境调参。

输出 mIoU、per-class IoU、合并透明前景 IoU、前景 Dice、固定容差的边界 F1。评价恢复原图尺寸；各模型用同样协议。缺失类别平均方式、边界容差、resize 顺序写清楚。

鲁棒性入口支持固定强度与随机种子的亮度、模糊、JPEG 测试，保留干净输入对照。生成原图/真值/S0/最终模型并列图片，包含固定选择的失败案例。图表全部读取真实结果文件，不硬编码好看的成绩。

## 六 导出与跨运行时一致性

在工程早期就对随机权重学生验证导出链路。随机权重文件必须明确标成 smoke，仅用于兼容检查。正式导出读取训练 checkpoint 和配置，不能误用随机模型。

学生导出固定 batch=1、固定输入、三类浮点 logits。默认尝试适合旧解析器的 ONNX opset 11/12 候选，依据实际导出工具与 Nano 解析器确定，锁定最终组合。遇到不支持算子，优先改学生推理路径为标准算子，不先写自定义 TensorRT 插件。

导出阶段不含教师、损失和边界辅助头；在 CPU 或本机 GPU 上比较 PyTorch 与 ONNX Runtime 输出，保存最大/平均绝对差、掩膜一致率及可能的近似误差。不只验证“文件存在”。

前处理和后处理只有一套共享实现，统一 RGB/BGR、归一化、等比缩放填充、logits 上采样和恢复原图。掩膜离散后只能用最近邻处理；不要让离线评价和现场演示使用不同坐标逻辑。

## 七 Nano 部署代码必须写全

假设目标是原版 Jetson Nano 4GB、JetPack 4.6.x、该系统配套 TensorRT 8.x，实际以目标板检查结果为准。不要混用 Orin Nano / JetPack 6 / TensorRT 10 的接口。原版 Nano 以 FP32/FP16 为核心方案，不安排 INT8 为必做。

即使本机没有 Nano，也必须交付能在目标环境运行的实际实现：环境检查、ONNX 到引擎构建、FP32/FP16 两个模式、TensorRT Python 推理、视频/摄像头入口、计时与资源采集工具、详细启动说明。禁止只留下 pass、NotImplementedError 或“组员自行实现”。没有真实 Nano 时，这些文件标注“实现完成，目标硬件未验证”，不能写“部署成功”。

Nano 运行代码兼容板上实际 Python；如尚未知，按旧版系统 Python 可兼容的语法规划并在文档注明待确认，不直接使用训练端最新语法。目标运行依赖与训练环境分开，不要求在 Nano 安装完整训练栈。

引擎在 Nano 构建，不把 PC engine 当可移植权重。TensorRT Python runner 与现有系统版本对齐，支持正确的 CUDA 上下文、缓冲区、同步与资源释放。若无法实测相关 API，依据对应版本官方文档检查，并将未验证点逐项列出。

性能工具区分纯推理和应用端到端，预热后测量均值/P50/P95、处理 FPS；同步与异步模式可切换。异步采用有界队列保留新帧，报告丢帧和帧龄，不能将摄像头标称 FPS 当处理 FPS。接入 tegrastats 日志，记录功耗模式、温度、共享内存和利用率；读不到的数值标 unavailable。

提供 256/384/512 配置、FP32/FP16 比较、十分钟持续运行的统一脚本。没有目标板时只交工具，不生成虚假板端数据。至少保留不依赖摄像头的本地视频路径。
